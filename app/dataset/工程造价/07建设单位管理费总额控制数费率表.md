## 建设单位管理费总额控制数费率表

| 单位:万元 |  |
|-------|--|
|       |  |

| 项目总概算         | 费率(%) | 算例     |                                   |
|---------------|-------|--------|-----------------------------------|
|               |       | 工程总概算  | 建设单位管理费                           |
| 1000 以下       | 1.5   | 1000   | 1000×1.5%<br>= 15                 |
| 1001–5000     | 1.2   | 5000   | 15 + (5000-1000)×1.2<br>= 63      |
| 5001—10000    | 1.0   | 10000  | 63 + (10000-5000)×1.0<br>= 113    |
| 10001—50000   | 0.8   | 50000  | 113 + (50000-10000)×0.8<br>= 433  |
| 50001—100000  | 0.5   | 100000 | 413 +(100000-50000)×0.5<br>= 683  |
| 100001—200000 | 0.2   | 200000 | 683 +(200000-100000)×0.2<br>= 883 |
| 200000 以上     | 0.1   | 300000 | 883 (300000-200000)×0.1<br>= 983  |

来源:《基本建设财务管理规定》(财建[2002]394 号文)
