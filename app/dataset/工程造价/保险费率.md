## 九、工程建设其他费

## 1、工程保险费

计算公式:

## 工程保险费=(含税建安工程造价+设备及工器具购置费)×工程保险费费率

工程保险费费率区分工程类别及特征、参考范围和推荐费率如表7所示,表7所列项目之外的工程项目的工程保险费资率可根据市场调查确定。

| 丁程 室别   | 丁程特征          | 参考范围    |
|---------|---------------|---------|
| 房屋建筑    | 30层以下         | 0.6~1.0 |
|         | 30层(含) 至60层   | 0.8~1.2 |
|         | 60层及以上        | 0.9~2.4 |
| 市政道路    | 含管线、综合管廊等配套设施 | 0.8~1.2 |
| 桥梁      | 普通桥梁          | 1.2~2.0 |
|         | 斜拉索桥、悬索桥      | 3.6~7.2 |
|         | 跨海大桥          | 5.4~9.0 |
| 地铁区间、车站 | 地下部分(含区间隧道)   | 6~10    |
|         | 地上、高架部分       | 1.0~2.5 |
| 勝道      |               | 4~9     |
