# 《烈马驯服》最终版 PRD

## 1. 产品概述

《烈马驯服》是一款第一人称体感像素游戏。

玩家扮演一位经验丰富的马师，以第一人称视角骑上随机遇到的烈马，体验一场高张力的驯服挑战。每匹马都有自己的颜色、级别和性格倾向，并由大模型 Agent 驱动，在骑乘过程中随机做出扬蹄、甩头、前冲、重踏、躁动等动作。玩家需要通过摄像头识别到的手部和上肢动作，及时作出真实的控缰、稳身和安抚操作。如果稳定值归零，就会被甩下马，挑战失败；如果坚持到目标时间，就会驯服成功，并把这匹马收入自己的马厩收藏。

## 2. 一句话定义

一款通过真实身体动作驯服随机烈马、并持续收集不同马匹的第一人称像素风体感养成游戏。

## 3. 核心卖点

- 第一人称骑乘代入感强，玩家一上手就能理解自己“正在马背上”
- 输入动作贴近真实驯马语义，以手部和上肢动作为核心
- Agent 驱动的烈马具备随机行为和现场感
- 每局随机遇马，挑战成功即可收集，形成持续游玩目标
- 马匹按颜色和 `S/A/B/C` 级别区分，具备收藏价值和惊喜感
- 黑客松演示效果强，用户动作与游戏反馈关系直观

## 4. 目标用户

- 喜欢轻互动、强反馈小游戏和收集养成元素的普通用户
- 黑客松评委与现场体验者
- 对 AI Agent 驱动角色行为感兴趣的观众

## 5. 核心玩法循环

1. 进入开始页
2. 查看当前收藏、已收集数量和本局挑战入口
3. 获取摄像头权限
4. 完成动作校准
5. 系统随机生成一匹待驯服马
6. 展示马匹外观、颜色、级别和简短性格标签
7. 进入第一人称驯马挑战
8. 烈马随机做出危险动作
9. 玩家用手部 / 上肢动作作出对应应对
10. 做对则稳定值维持或回升，做错则稳定值下降
11. 稳定值归零则坠马失败
12. 坚持到目标时间则驯服成功
13. 成功后获得该马，进入结算与收集展示

## 6. 世界观与角色设定

## 6.1 主角

- 身份：经验丰富的马师
- 气质：冷静、可靠、动作利落
- 作用：以第一人称视角代表玩家

## 6.2 烈马

- 身份：本作核心对手与互动对象
- 特征：强壮、聪明、倔强、不可预测
- 玩法意义：动态行为来源，不是固定脚本敌人

## 6.3 马匹收集设定

每次挑战开始时，系统会随机生成一匹待驯服马。马匹由以下维度组成：

- 颜色
- 级别
- 性格倾向

### 推荐颜色池

- 棕马
- 黑马
- 白马
- 灰马
- 栗红马
- 花斑马

### 推荐级别

- C：常见
- B：较少见
- A：稀有
- S：极稀有

### 推荐性格标签

- 暴躁
- 灵巧
- 顽固
- 稳中带野
- 爆发型

## 6.4 主题气质

- 像素风
- 紧张但不恐怖
- 有挑战感
- 有动物互动张力
- 成功后有强烈成就感

## 7. 最终视角方案

本项目最终确定采用第一人称方案。

### 表现方式

- 玩家像坐在马背上
- 画面底部能看到马耳、鬃毛、缰绳或马头前部
- 烈马动作通过镜头晃动、前推、上扬、侧偏、下沉来表达
- 驯马场在前方展开，HUD 叠加在视图上

### 方案优势

- 代入感最强
- 更容易表达“快被甩下去”的紧张感
- 更适合把手部 / 上肢动作包装成真实骑乘输入
- 更适合展示控缰、稳身和安抚的动作语义

### 落地原则

- 不把完整主角模型作为主视图核心
- 重点表现马耳、鬃毛、缰绳、视角偏移与场景晃动
- 用画面语言表达烈马状态，而不是依赖复杂角色动画

## 8. 核心规则设计

## 8.1 胜负条件

成功：

- 在限定时间内没有被甩下马
- 成功后获得当前这匹马

失败：

- 稳定值归零
- 或在关键连续失败后直接坠马

## 8.2 核心资源

建议使用一个核心状态：

- 稳定值

规则：

- 初始为 100
- 做对动作则恢复或维持
- 做错动作则下降
- 遭遇高危险动作且未成功应对时，大幅下降

## 8.3 时间目标

- 30 秒新手版
- 45 秒标准版
- 60 秒挑战版

黑客松首版推荐：

- 45 秒标准版

## 8.4 收集与养成规则

### 收集规则

- 每次开局只遇到 1 匹随机马
- 驯服成功即可获得该马
- 驯服失败则本次不获得

### 马厩展示规则

建议在开始页和结算页都提供“我的马厩”入口，展示：

- 已收集马匹数量
- 每匹马的颜色
- 每匹马的级别
- 是否为首次收集

### 稀有度体验

首版先做到：

- `S/A/B/C` 标签
- 对应不同卡片边框颜色
- 首次获得时的高光动画

后续可扩展：

- 更高等级更难驯服
- 稀有马拥有更独特的动作节奏
- 收集图鉴和完成度奖励

## 9. 烈马 Agent 行为设计

## 9.1 设计目标

烈马需要看起来像“有自己的脾气”，而不是固定循环动画。

建议由 Agent 或规则模拟层负责：

- 决定下一步动作
- 决定动作强度
- 决定是否连续发难
- 根据玩家表现调整节奏

## 9.2 推荐动作池

- 扬蹄后仰
- 向左剧烈甩动
- 向右剧烈甩动
- 前冲失控
- 重踏下沉
- 呼吸急促后的突然躁动
- 短暂平静后再次爆发

## 9.3 不同马匹的行为差异

为了让收集不只是换皮，建议不同马匹有轻量行为倾向：

- 暴躁型：高频出招、短冷却
- 灵巧型：左右甩动更多
- 顽固型：重踏和后仰更多
- 爆发型：前段平静，后段突然连续出招

首版只需要在配置表中体现权重不同即可。

## 10. 玩家动作映射

输入系统采用“手部 / 上肢主导，头部辅助”的动作识别方式。

## 10.1 输入设计原则

- 主输入优先使用大动作，不做精细手指识别
- 优先识别双手、手腕、肘部、肩部和躯干重心变化
- 头部动作只作为辅助，不再作为主要玩法输入
- 每个动作都要能在现实驯马语义上说得通

## 10.2 主动作映射

1. 左手拉缰
- 应对：烈马向左甩动
- 语义：向左控缰，顺势稳住偏移

2. 右手拉缰
- 应对：烈马向右甩动
- 语义：向右控缰，顺势稳住偏移

3. 双手稳缰
- 应对：烈马前冲、连续躁动、快速小幅乱动
- 语义：双手握缰，强行建立控制

4. 双手下压安抚
- 应对：烈马扬蹄后仰 / 情绪爆发前摇
- 语义：压低重心、安抚烈马、压住节奏

## 10.3 辅助动作

- 稳定保持：对应平静窗口和恢复阶段
- 轻微点头 / 平稳呼吸：对应安抚阶段

## 11. 单局节奏设计

### 前段：试探

- 烈马动作频率较低
- 系统提示更明确
- 先以左拉缰、右拉缰、双手稳缰为主

### 中段：发力

- 烈马变招更频繁
- 左右甩动、前冲与重踏开始交错出现
- 稳定值压力开始上升

### 后段：决胜

- Agent 动作更激烈
- 可能连续出招
- 会出现“后仰 + 甩动”或“重踏 + 前冲”这样的连续压力
- 成功坚持后直接进入高光结算

## 12. 页面结构

## 12.1 开始页

- 游戏标题
- 一句话介绍
- 马师与烈马主题视觉
- 我的马厩入口
- 已收集数量
- 开始按钮
- 摄像头权限提示

## 12.2 校准页

- 摄像头画面
- 身体识别区域
- 左手拉缰测试
- 右手拉缰测试
- 双手稳缰测试
- 双手下压测试
- “准备上马”提示

## 12.3 战斗页

- 第一人称骑乘画面
- 烈马当前状态表现
- 稳定值条
- 坚持时间
- 当前危险提示
- 当前应对动作提示
- 当前马匹颜色 / 级别标签
- 摄像头小窗
- 成功 / 失败反馈

## 12.4 结算页

- 是否驯服成功
- 当前马匹卡片
- 是否首次收集
- 坚持时间
- 最危险阶段表现
- 最佳连续应对次数
- 评级
- 再来一局按钮

## 13. 前端表现设计

## 13.1 烈马动作反馈

必须让玩家明显看懂马在做什么：

- 后仰时镜头上扬
- 左右甩动时画面左右偏移
- 前冲时画面前推或速度线增强
- 重踏时上下震动和扬尘
- 平静时回到中性状态

## 13.2 成功反馈

- 绿色或金色稳定反馈
- 稳定值上升或停止下降
- 烈马动作短暂缓和
- HUD 显示 `Good / Perfect`
- 缰绳和画面有明显“控住了”的演出

驯服成功时：

- 弹出马匹收集卡
- 显示颜色与级别
- 若为新马则出现“新伙伴加入马厩”高光提示

## 13.3 失败反馈

- 画面抖动增强
- 稳定值下降
- 红色危险提示
- 接近失败时出现强烈坠马预警

## 14. AI 亮点表达

- 这不是固定出招表
- 烈马由 Agent 控制，会随机做动作
- 玩家必须即时观察并用身体回应
- 每一局都可能遇到不同级别、颜色和性格的马

## 15. MVP 范围

### 必做

- 第一人称驯马挑战
- 随机遇马机制
- 至少 4 种烈马动作
- 至少 4 种手部 / 上肢应对动作
- 稳定值系统
- 坠马失败
- 坚持时间成功
- 成功收集当前马匹
- 结算页

### 建议做

- Agent 随机出招包装
- 第一人称高质量镜头演出
- 成功 / 失败明显特效
- 马厩展示页
- 稀有度标签和首次收集动画

### 不做

- 开放世界
- 多匹马实时切换
- 复杂剧情
- 装备成长

## 16. 验收标准

1. 用户一眼能理解自己在“驯服烈马”
2. 用户一进入战斗页就能感受到自己正骑在马背上
3. 烈马会明显做出不同危险动作
4. 玩家做出的手部 / 上肢动作能与烈马动作形成明显对应
5. 成功坚持一定时间后能获得当前马匹并进入结算
6. 失败时能看到明显坠马或失衡后果
7. 用户能感知到马匹有颜色和级别差异，并形成收集目标
8. 评委能快速理解“AI Agent + 摄像头体感 + 收集养成”的亮点

## 17. 总结

《烈马驯服》的最终方向是：

- 第一人称骑乘
- 手部 / 上肢控缰应对
- Agent 驱动烈马
- 随机遇马
- 驯服后加入收藏

这套方案兼顾了即时演示效果、题材统一性和持续收集动力。
