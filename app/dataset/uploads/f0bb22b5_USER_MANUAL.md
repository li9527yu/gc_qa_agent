> 适用版本：智诚大模型对话系统（Streamlit 前端 + Easy-RAG 后端）
> 服务地址：`http://localhost:8001`
> 前端入口：`/home/tpc/suda/rag/h_rag/server/web_app.py`

---

## 一、系统简介

本系统是一款面向**工程造价领域**的智能问答助手，基于 RAG（检索增强生成）技术构建。用户可通过自然语言进行两类核心交互：

1. **知识问答**：基于上传的文档语料库回答专业问题
2. **价格推荐**：查询材料的市场信息价、厂商报价、智诚信息价

系统会自动识别用户意图，并调用相应的后端服务进行流式回答。

## 二、环境准备与启动

### 2.1 启动后端服务

在启动前端之前，请确保以下服务已正常运行：

```bash
# 1. 启动 Milvus 向量数据库
cd /home/tpc/suda/rag/easy-rag
docker-compose up -d

# 2. 启动 LLM 服务（选择一种即可）
bash start_vllm_quantized_model.sh   # 推荐，响应最快
# 或 bash start_awq_model.sh
# 或 bash start_original_model.sh

# 3. 启动 Easy-RAG 主服务
python -m app.api_server
# 或 uvicorn app.api_server:app --host 0.0.0.0 --port 8001
```

### 2.2 启动前端界面

```bash
cd /home/tpc/suda/rag/h_rag/server
streamlit run web_app.py
```

启动后，浏览器将自动打开前端页面（默认地址：`http://localhost:8501`）。

## 三、界面功能介绍

页面采用**三栏式布局**：左侧边栏（功能控制区）、中间主区域（对话区）、底部（参考文档区）。

### 3.1 左侧边栏

#### 📈 图表设置
- **数据量阈值**：设置价格查询时绘制图表的数据量门槛（默认 10 条）
  - 当查询返回的数据条数 **≤ 阈值** 时，系统仅展示原始数据表格，不生成图表
  - 当数据条数 **> 阈值** 时，自动渲染「价格分布图」和「价格散点图」

#### 📤 上传知识库文件
- **支持格式**：`TXT`、`PDF`、`MD`
- **大小限制**：单个文件 ≤ 200MB
- **操作方式**：
  1. 点击或拖拽文件到上传区域
  2. 点击「开始上传」按钮
  3. 上传成功后，系统将**自动重建知识库**，期间页面会显示进度条
  4. 重建完成后会提示「数据库更新完成，可以开始提问啦！」

> ⚠️ **注意**：知识库更新期间，聊天输入框将被禁用，无法提问。

#### 📁 文件管理
- **刷新文件列表**：点击「🔄 刷新文件列表」查看当前知识库中的所有文件
- **文件信息**：显示文件名、大小（MB）、修改时间
- **批量删除**：
  1. 在文件列表中勾选需要删除的文件
  2. 点击右下角悬浮的「🗑️ 批量删除」按钮
  3. 在弹窗中确认删除
  4. 删除后系统同样会自动重建知识库

### 3.2 中间主区域（聊天对话区）

#### 欢迎语
首次进入或清空对话后，页面显示：
> "👋 欢迎使用RAG对话助手"  
> "🌿 很高兴在此与你相遇，愿我们一同在知识的枝叶间，探寻微光与辽阔。"

#### 提问方式
在底部输入框中输入问题，按回车发送。系统支持以下三类意图的自动识别：

| 用户意图 | 示例问题 | 系统行为 |
|----------|----------|----------|
| **知识问答** | "什么是清单计价？" | 调用 RAG 检索文档，流式生成回答 |
| **价格推荐** | "304不锈钢价格多少？" | 查询材料价格数据库，返回分析结果和图表 |
| **其他问题** | "今天几月几号？" | 由大模型直接回答 |

> 🛡️ **安全拦截**：若检测到 `dangerous_sql` 意图（如"删除数据库"），系统将拒绝回答并提示风险。

#### 流式回答效果
- 发送问题后，界面显示「模型思考中，请稍候...」
- 回答内容会**逐字流式显示**，提升交互体验
- 回答完成后，相关内容会自动同步到「参考文档」区域

### 3.3 参考文档区（页面底部）

每次对话完成后，页面底部会展示该回答所依据的参考资料：

- **知识问答**：显示 RAG 检索到的文档片段，包括文件名、相似度得分、检索方式、原文内容
- **价格推荐**：显示价格原始数据表格（Markdown 表格格式）

用户可通过下拉框切换查看不同的参考文档片段。

## 四、核心操作流程

### 4.1 知识问答流程

1. 用户输入问题（如："索赔的定义是什么？"）
2. 系统自动识别意图为 `knowledge_qa`
3. 后端检索向量数据库和 BM25 索引，获取相关文档片段
4. 重排模型对文档进行精排序
5. LLM 基于检索到的上下文生成流式回答
6. 前端展示回答内容，并在底部列出参考文档

### 4.2 价格推荐流程

1. 用户输入问题（如："混凝土的单价是多少？"）
2. 系统自动识别意图为 `price_recommendation`
3. 后端调用价格查询 API（信息价 / 厂商报价 / 智诚信息价）
4. 返回价格原始数据和分析结论
5. 前端根据数据量判断是否渲染图表：
   - **数据量充足**（> 阈值）：展示「价格分布频数图」和「价格散点图」
   - **数据量不足**（≤ 阈值）：仅展示原始数据表格，并提示"不建议进行数据分析和价格推荐"

> 💡 **提示**：若问题中未包含渠道关键词（如"信息价"、"厂商报价"），系统会提示"请提供查询渠道关键词"。

### 4.3 文件上传与管理流程

#### 上传文件
1. 在左侧边栏选择文件（支持多选）
2. 点击「开始上传」
3. 等待「知识库正在更新...」进度完成
4. 更新完成后即可基于新文档提问

#### 删除文件
1. 点击「🔄 刷新文件列表」
2. 勾选要删除的文件
3. 点击右下角「🗑️ 批量删除」
4. 在弹窗中点击「确认」
5. 等待知识库重建完成

## 五、界面交互细节

### 5.1 知识库更新状态

- 上传或删除文件后，页面会进入「知识库正在更新...」状态
- 此时聊天输入框被禁用，显示「知识库更新中，暂不可提问」
- 系统每 2 秒轮询一次任务状态，最多等待约 20000 秒（进度条会循环走动）
- 更新成功后会自动刷新页面

### 5.2 价格图表展示

当价格查询返回的数据量超过阈值时，回答下方会自动展开两个图表：

| 图表名称 | 说明 |
|----------|------|
| **价格分布频数图** | 将价格按区间分箱（默认 5 个区间），展示各区间的数量分布 |
| **价格散点图** | 以时间为横轴、价格为纵轴，展示各时间点的价格分布情况 |

### 5.3 参考文档展示差异

| 问答类型 | 参考文档内容 |
|----------|--------------|
| 知识问答 | 文档片段原文 + 文件名 + 相似度 + 检索方式 |
| 价格推荐 | Markdown 格式的价格原始数据表格 |

## 六、注意事项

1. **服务依赖**：使用前端前必须确保后端服务（`localhost:8001`）、Milvus 和 LLM 服务均已启动。
2. **文件格式**：仅支持 `TXT`、`PDF`、`MD` 三种格式，其他格式需先转换。
3. **知识库重建时间**：上传/删除大文件后，向量化和入库可能需要数秒到数分钟，请耐心等待。
4. **价格查询渠道**：提问时尽量包含具体渠道词，如"信息价"、"厂商报价"、"智诚信息价"，以获得更精准的结果。
5. **上下文记忆**：系统保留最近 5 轮对话历史（最多 10 条消息），支持多轮连续问答。
6. **浏览器兼容性**：推荐使用 Chrome、Edge 等现代浏览器访问 Streamlit 页面。

## 七、常见问题

### Q1: 页面提示"知识库更新中，暂不可提问"，需要等多久？
**A**: 取决于文件大小和数量，通常几秒到几分钟。若长时间未恢复，可刷新页面或检查后端日志。

### Q2: 上传文件后为什么还是无法回答新文档的内容？
**A**: 请确认上传后是否等待「数据库更新完成」的提示出现。若未出现，可能是 Milvus 或 Embedding 模型服务异常。

### Q3: 价格查询没有返回图表，只显示了表格？
**A**: 说明返回的数据条数 ≤ 您设置的阈值（默认 10 条）。您可以在左侧边栏调低阈值，或确认数据库中是否有更多相关样本。

### Q4: 提问后被提示"用户未提及任何渠道关键词"？
**A**: 价格查询需要明确渠道，请在问题中加入"信息价"、"厂商报价"或"智诚信息价"等关键词。

### Q5: 如何清空对话历史？
**A**: 当前版本未提供一键清空按钮，可通过刷新浏览器页面来重置对话（文件和知识库状态不受影响）。
