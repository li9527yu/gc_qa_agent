## 总结
执行流程可以概括为：
1. \*\*入口统一\*\*：所有查询通过 `/api/v1/query/intent` 进行意图识别
2. \*\*分支处理\*\*：
- \*\*知识问答\*\*：BM25 + 向量检索 → 重排序 → LLM 生成
- \*\*价格推荐\*\*：渠道识别 → 实体抽取 → 数据查询 → 分析 → LLM 生成
3. \*\*流式响应\*\*：所有接口支持 SSE 流式返回，提升用户体验
4. \*\*对话管理\*\*：支持多轮对话和渐进式实体补全
5. \*\*数据一致性\*\*：语料库变化自动检测，触发向量库重建
整个系统采用\*\*模块化设计\*\*，各组件职责清晰，便于维护和扩展。
