# 价格推荐功能说明文档

## 一、功能概述

价格推荐功能是 Easy-RAG 系统的核心模块之一，专注于工程造价领域的材料价格智能查询与推荐。系统通过多维度数据分析和智能算法，从信息价、厂商报价、智诚信息价等多个渠道为用户提供准确、可靠的材料价格参考。

### 1.1 核心能力

- **多渠道数据查询**：支持信息价、厂商报价、智诚信息价三大渠道
- **智能价格分析**：基于统计学方法和机器学习算法进行价格分档推荐
- **数据质量保障**：自动过滤异常值，确保推荐价格的可靠性
- **模糊匹配过滤**：智能匹配用户查询与数据库中的材料名称

### 1.2 应用场景

- 工程造价编制时的材料价格查询
- 招投标阶段的价格参考
- 成本核算与预算编制
- 市场价格趋势分析

## 三、数据过滤算法详解

数据过滤算法负责将API返回的原始数据与用户查询条件进行智能匹配，过滤掉不相关的记录。

### 3.1 算法位置

- **文件**：`app/utils/fillter_tools.py`
- **核心函数**：`filter_items()`

### 3.2 算法原理

采用**基于字符级相似度的模糊匹配算法**，结合**多维度阈值控制**策略。

#### 3.2.1 相似度计算方法

```python
# 综合相似度 = 字符相似度 * (1 - α) + 顺序相似度 * α
score = char_sim * (1 - alpha) + order_sim * alpha
```

**1. 字符相似度（Jaccard 系数）**

计算两个字符串中共同字符的比例：

```
char_sim = |A ∩ B| / |A ∪ B|

示例：
  查询词："铝合金幕墙型材"
  目标词："铝合金幕墙型材（阳极氧化）"
  
  A ∩ B = {铝, 合, 金, 幕, 墙, 型, 材} = 7
  A ∪ B = {铝, 合, 金, 幕, 墙, 型, 材, （, 阳, 极, 氧, 化, ）} = 13
  
  char_sim = 7 / 13 ≈ 0.538
```

**2. 顺序相似度（最长公共子序列）**

计算字符顺序的一致性：

```
order_sim = 2 * LCS(A, B) / (len(A) + len(B))

示例：
  查询词："镀锌方钢"
  目标词："热镀锌方钢管"
  
  LCS = "镀锌方钢" = 4
  order_sim = 2 * 4 / (4 + 5) = 8/9 ≈ 0.889
```

**3. 综合相似度**

```python
# 默认 alpha = 0.4，表示更重视字符相似度
score = char_sim * 0.6 + order_sim * 0.4
```

#### 3.2.2 阈值控制策略

```python
# 双阈值过滤机制
if score >= T_keep:      # T_keep 默认 0.75
    保留该记录          # 高置信度匹配
elif score <= T_drop:    # T_drop 默认 0.50
    丢弃该记录          # 低置信度匹配
else:
    待定区记录          # 中等相似度，保留
```

| 相似度区间 | 处理策略 | 说明 |
|-----------|---------|------|
| ≥ 0.75 | **强制保留** | 高置信度匹配，与查询强相关 |
| 0.50 ~ 0.75 | 保留 | 中等相似度，可能是相关变体 |
| ≤ 0.50 | **强制丢弃** | 低置信度匹配，视为无关数据 |

## 四、价格推荐算法详解

价格推荐算法基于统计学和机器学习方法，对过滤后的价格数据进行深度分析，生成可靠的价格推荐。

### 4.1 算法位置

- **文件**：`app/utils/price_tools.py`
- **核心函数**：

  - `analyze_by_unit()` - 按单位分组分析
  - `recommend_price_mode()` - K-means聚类推荐
  - `remove_outliers()` - 异常值过滤

┌─────────────────┐

### 4.3 详细步骤说明

#### 4.3.1 步骤1：异常值过滤（IQR 方法）

**原理**：使用四分位距（Interquartile Range）识别并剔除异常价格。

```
计算过程：
  1. 计算 Q1（第25百分位数）和 Q3（第75百分位数）
  2. 计算 IQR = Q3 - Q1
  3. 确定异常值边界：
     - 下界 = Q1 - 1.5 × IQR
     - 上界 = Q3 + 1.5 × IQR
  4. 剔除超出边界的值
```

**示例**：

```
价格数据：[20, 22, 23, 24, 25, 26, 27, 28, 30, 100]

Q1 = 22.5（第25百分位）
Q3 = 28.5（第75百分位）
IQR = 28.5 - 22.5 = 6

下界 = 22.5 - 1.5 × 6 = 13.5
上界 = 28.5 + 1.5 × 6 = 37.5

异常值：100（超出上界37.5）
过滤后：[20, 22, 23, 24, 25, 26, 27, 28, 30]
```

#### 4.3.2 步骤2：统计分析

对过滤后的数据计算统计指标：

| 指标 | 计算方法 | 用途 |
|-----|---------|------|
| 样本数量 | count | 数据可信度评估 |
| 价格区间 | [min, max] | 了解价格波动范围 |
| 平均值 | mean | 总体价格水平 |
| 中位数 | median | **单一价格推荐依据** |
| 标准差 | std | 价格波动程度 |
| 95%置信区间 | mean ± 1.96×SE | 价格区间估计 |

#### 4.3.3 步骤3：K-means 聚类推荐

**目标**：判断价格数据应该返回**单一价格**还是**分档价格**（中档/高档）。

**算法逻辑**：

```python
# 1. 尝试 k=2 聚类
kmeans = KMeans(n_clusters=2, random_state=42).fit(prices)
labels = kmeans.labels_
centers = sorted(kmeans.cluster_centers_.flatten())  # 聚类中心（排序后）

# 2. 计算轮廓系数（Silhouette Score）
#    衡量聚类效果的优劣，范围 [-1, 1]
#    越接近1表示聚类越合理
sil = silhouette_score(prices, labels)

# 3. 计算两簇差距比例
gap = abs(centers[1] - centers[0])
gap_ratio = gap / mean_price

# 4. 检查是否存在小簇
small_cluster = any(counts < 0.1 × total_count)  # 占比<10%视为小簇

# 5. 判定规则
if sil >= 0.5 and gap_ratio >= 0.3 and not small_cluster:
    推荐模式 = "two-tier"  # 两档价格
    推荐价格 = [center1, center2]
else:
    推荐模式 = "single"    # 单一价格
    推荐价格 = [median]
```

**判定条件说明**：

| 条件 | 阈值 | 说明 |
|-----|------|------|
| 轮廓系数 | ≥ 0.5 | 确保两簇分离明显，不是随机分布 |
| 差距比例 | ≥ 0.3 | 两档价格差异至少30%，有实际区分意义 |
| 小簇检查 | 无小簇 | 确保每档都有足够样本支撑（≥10%） |

**示例1：单一价格推荐**

```
价格数据分布（过滤后）：
[22, 23, 23, 24, 24, 24, 25, 25, 26]

K-means 聚类（k=2）：
  簇1：[22, 23, 23, 24] 中心≈23
  簇2：[24, 25, 25, 26] 中心≈25

轮廓系数：0.32（< 0.5，聚类效果不佳）
差距比例：(25-23)/24 ≈ 0.083（< 0.3）

判定结果：single
推荐价格：[24.0]（中位数）
```

**示例2：两档价格推荐**

```
价格数据分布（过滤后）：
[20, 21, 22, 23, 35, 36, 37, 38, 39, 40]  ← 明显分为两组

K-means 聚类（k=2）：
  低档：[20, 21, 22, 23] 中心=21.5
  高档：[35, 36, 37, 38, 39, 40] 中心=37.5

轮廓系数：0.72（≥ 0.5，聚类效果好）
差距比例：(37.5-21.5)/29 ≈ 0.55（≥ 0.3）
小簇检查：低档占40%，高档占60%（均≥10%）

判定结果：two-tier
推荐价格：[21.5, 37.5]（低档/高档）
```

## 七、总结

### 7.1 算法优势

1. **智能匹配**：模糊匹配算法有效处理材料名称变体
2. **质量保障**：IQR异常值过滤 + K-means聚类确保推荐可靠性
3. **灵活推荐**：根据数据分布自动选择单一价格或分档价格
4. **可解释性**：提供详细的推荐理由和统计指标

### 7.2 适用限制

1. **样本依赖**：K-means需要至少4个样本才能有效聚类
2. **阈值固定**：当前阈值（0.5/0.3）为经验值，可能不适用于所有场景
3. **中文特化**：分词和匹配算法针对中文优化，其他语言效果可能下降

### 7.3 未来优化方向

1. 引入历史价格趋势分析
2. 支持用户自定义阈值配置
3. 增加价格预测功能（时间序列分析）
4. 引入更多数据源进行交叉验证

## 附录：算法公式汇总

### A.1 字符相似度（Jaccard）

$$\text{CharSim}(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

### A.2 顺序相似度（LCS）

$$\text{OrderSim}(A, B) = \frac{2 \times \text{LCS}(A, B)}{|A| + |B|}$$

### A.3 综合相似度

$$\text{Score} = \text{CharSim} \times (1 - \alpha) + \text{OrderSim} \times \alpha$$

### A.4 IQR 异常值边界

$$\text{Lower} = Q_1 - k \times (Q_3 - Q_1)$$
$$\text{Upper} = Q_3 + k \times (Q_3 - Q_1)$$

其中 $k = 1.5$

### A.5 95% 置信区间

$$\text{CI} = \bar{x} \pm 1.96 \times \frac{s}{\sqrt{n}}$$

其中 $\bar{x}$ 为样本均值，$s$ 为样本标准差，$n$ 为样本数量
